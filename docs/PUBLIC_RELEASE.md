# 公開版本範圍

此版本以獨立初始提交公開，不包含來源倉庫的歷史、內部文件、實際環境設定或上傳資料。

本倉庫的維護範圍是 AMD 比賽版；DeepSeek 自有正式產品在另一個倉庫維護。版本分工的本機備忘 `agent.md` 與入口 `AGENTS.md` 均列入 Git 忽略，不屬於公開內容。

2026-10-29 維護方式：AMD 比賽版直接使用 `main`，本機只保留 `main`；版本分工與本機備忘忽略規則一併納入，不另開 PR。本輪沒有變更執行程式、模型或資料庫。

- 以七筆合成房源取代爬取資料；連動的 seed 與測試使用相同合成識別碼。
- 移除正式資料備份、真人資料搬移及從正式庫複製測試庫的維運腳本。
- 移除通知服務寫死的個人 tunnel 網址；公開版本本機預設為 localhost。
- 根目錄設定範例選擇 llama.cpp，金鑰留空；AMD GPU 執行與效能尚待實測。
- 保留政府公開租約 PDF，供既有來源校驗與不可變版本驗證使用。

`npm run check:public` 檢查已追蹤檔案中的禁止路徑、常見憑證格式與個人 tunnel 網址。這是發布前的輔助檢查，不能代替人工檢查或證明所有文字均無敏感資料。

## 已知測試限制

整理時曾以完整 Node 測試驗證，共 927 項：907 通過、15 失敗、5 略過。15 項失敗與來源版本相同，涉及舊卡片預期、固定日期、屋況照片與附件候選；公開整理未增加失敗，也不宣稱修復這些既有問題。公開倉庫僅保留 AI 設定、HTTP 客戶端與公開檢查測試，避免發布無關的舊資料樣本；新加入的公開檔案檢查測試通過。合成資料 seed 的外鍵與 SQLite 完整性檢查通過。

最終公開範圍的 Node 測試 25 項全部通過。Python 協調器純單元測試 31 項全部通過。測試沿用本機既有依賴環境；尚未在全新 Linux 主機驗證安裝與啟動。

目前沒有真人 LINE、Lab GPU、真實模型或 GCP 部署驗收；請勿將公開程式碼直接視為已驗收的正式服務。
